ConCar Backup Rclone

Aplicativo de uso pessoal destinado à realização de backups automáticos do banco de dados ConCar.

A integração utiliza o Rclone e a Google Drive API para armazenar backups criptografados na conta Google Drive autorizada pelo proprietário.

Os arquivos são organizados na pasta BKP_ConCar, com identificação por data e hora.
